Custom WebDAV sync

WebDAV sync uses your endpoint account over HTTPS. The credentials file on the WebDAV server is plaintext, so the server operator can read it. Endpoint credentials are saved only in this browser profile’s local extension storage.

Example: https://webdav.example.net/dav/multipass-sync.json

Configure a WebDAV file URL to begin.

Use HTTPS. HTTP is allowed only for localhost testing and is unencrypted. The file stored on WebDAV contains usernames and passwords in plaintext; HTTPS protects them in transit but not from the WebDAV server or its administrators. Files larger than 5 MiB are rejected. Automatic sync uses a common baseline and strong ETags; if both devices change, the remote file is deleted, a snapshot is empty, or the server does not return reliable ETags, automatic sync stops for review. Browser alarms may run later than the selected interval. Local browser storage is not a password vault.
