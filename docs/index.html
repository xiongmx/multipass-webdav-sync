MultiPass WebDAV Sync

MultiPass WebDAV Sync is an unofficial, independently maintained fork of MultiPass that adds optional, client-side-encrypted synchronization through your own HTTPS WebDAV server. This WebDAV-sync-enabled version is separate from the original MultiPass extension and is not an official Microsoft product.

It stores HTTP and HTTPS Basic authentication rules in an encrypted local vault.

When a website's URL matches one of your rules and it issues a Basic authentication challenge, the corresponding credentials are sent to that website.

Rules can match HTTP and HTTPS websites. Plain HTTP does not encrypt Basic credentials in transit, so prefer HTTPS and use HTTP only with trusted sites. Proxy-authentication and non-Basic challenges are rejected. The WebDAV provider can still see its account authorization, endpoint, request timing and size, and metadata such as ETags.

The extension has not been independently security-audited. The primary package targets Chromium Manifest V3; Edge Android Stable has not been verified on a real device and Android support is not claimed. Firefox and Firefox for Android builds are experimental.

Report an issue

If you want to report an issue, use the Github issue tracker: MultiPass WebDAV Sync issues.

Please make sure the issue is not already opened.

Use the development version

If you want to use the development version, follow those steps :

  1. Clone this fork : git clone --branch main https://github.com/xiongmx/multipass-webdav-sync.git.
  2. Enter the directory : cd multipass-webdav-sync.
  3. Install dependencies : npm ci.
  4. Build the extension : npm run build.
  5. Open the Extension panel in Chrome : Tools / Extensions.
  6. Make sure the "Developer mode" checkbox is checked.
  7. Click on "Load unpacked extension...", first browse to the directory where you cloned the extension and then select the build/chrome folder.
